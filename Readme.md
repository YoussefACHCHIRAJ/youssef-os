# Dotfiles

This repository contains the configuration for my Arch Linux workstation.

## What's included

- Hyprland configuration
- Waybar
- Hyprlock
- Hypridle
- Wlogout
- SwayNC
- Kitty
- Zsh
- VS Code settings
- Shell scripts and automations
- Package lists
- Wallpapers, themes, and fonts

## Goals

- Keyboard-first workflow
- Consistent design system
- Fast development environment setup
- Modular and maintainable configuration
